# 工资册 · M1 静态骨架

礼盒生产线的计件工资系统。
每条记录一行：**姓名 / 时间 / 礼盒名称 / 盒型 / 规格 / 件数 / 损耗 / 单价 / 金额 / 卡盒 / 贴码 / 备注**。

首次打开会生成 11 名计件工人和 8 名计时工人的档案，之后的增删改都保存在浏览器里，不需要服务器。

## 打开

推荐双击桌面的 **「打开工资系统」** 快捷方式（或项目里的 `打开工资系统.bat`）。启动器会先运行 `import-csv.ps1`，把 `data/1csv/*.csv` 全部生成为 `js/auto-csv-data.js`，页面加载时自动同步到 localStorage，再用浏览器打开 `index.html`。

也可以直接双击 `index.html`，但那样只会使用上一次生成的 CSV 快照；CSV 有改动时请用启动器。

### 自动导入规则

- `data/1csv` 下的全部 CSV 都会被读取（含「铁盒」盒型）
- 自动导入的记录带 `source: "auto-csv"`，每次打开会先删除再按当前 CSV 重新导入，CSV 是这部分数据的来源
- 手工新增/编辑的记录（没有 source 标记）会保留
- 与已有记录完全相同的行会跳过，不会重复
- 单价为空但金额有值的行，会用「金额 ÷ 有效件数」反推单价
- 备注列（第 12 列）会保留；页码列仅用于核对，不导入
- 页面右下角常驻状态条会显示「CSV 已就绪 N 行 · 快照 时间」，方便确认数据已加载
- 快照为空或未加载时，**不会删除已有数据**，只会提示用启动器重新生成
- 浏览器 localStorage 被清空也没关系：下次打开会按快照重新导入全部 CSV 记录

## 数据保存在哪里

首次打开会生成 11 名计件工人（太华、连玉、向金、秀琴、碧凤、丽慈、玉琴、郭碧玉、碧英、细金、丽清）和 8 条计时记录（8 名计时工人，每人先一条，可继续新增）。计件记录不内置假数据，通过 CSV 导入或手动新增。之后的新增、删除、修改都会自动存进浏览器的 localStorage（键名 `wage-ledger-v1`）。

旧版浏览器数据如果是 12 名示例工人（陈默、李秀兰……马小燕），打开页面时会一次性清理这些占位工人及其假记录，并补齐上面的 11 名真实工人；已是真实姓名的工人（例如丽清）保留原工号和数据。

数据只存在这台电脑的这个浏览器里，换浏览器或清理缓存就会丢失。想恢复示例数据：开发者工具 → Application → Local Storage → 删除 `wage-ledger-v1`，刷新页面。

## 计算规则

```
金额 = 规格 × 件数 × 单价 − 损耗 × 单价
```

盒型选项为 **50 / 饼干 / 40 / 陈皮 / 60 / 20 / 散茶 / 42**。
其中盒型为 **饼干** 或 **20** 时，损耗按一半扣：

```
金额 = 规格 × 件数 × 单价 − 损耗 ÷ 2 × 单价
```

计时工人是独立名单（和计件工人不共用），单独一页，**一行一条记录**，格式为 **姓名 / 时间 / 单价 / 金额**：

```
金额 = 时间 × 单价
```

- 判断逻辑在 `calc.js` 的 `isHalfLossType()`，表格里用 ½ 角标提示
- 金额全程用整数「分」计算，显示时再除以 100
- `unitPriceCents`、`rateCents` 都是记录里的单价快照，调价后不会改写历史数据
- 卡盒、贴码是勾选项（是/否），不参与金额计算
- 计时金额独立统计，不并入计件工资

## 这一版已经能做什么

- 生产记录页：按姓名分页（每页 20 条），姓名、时间、礼盒名称、盒型、规格、件数、损耗、单价全部可编辑
- 生产记录可以新增、删除（删除前确认），改动自动保存
- 计时页：一行一条记录，姓名 / 时间 / 单价 / 金额，金额 = 时间 × 单价，可新增、删除、编辑
- 三个列表页都有搜索：生产记录按姓名/工号/礼盒/盒型/日期，计时按姓名/工号，工人按工号/姓名/班组；搜索条件会写进地址栏 `?q=`
- 卡盒、贴码改成了勾选框；金额和底部合计实时重算
- 记录新增「备注」字段，可编辑；导入时卡盒/贴码里的文字会转入备注
- 盒型选到「20」或「饼干」时，½ 角标与减半公式即时生效
- 生产记录工具栏「导入 CSV」：选文件 → 预览校验 → 确认后追加写入；重复行自动跳过，金额按系统公式重算
- 工人页分「计件工人 / 计时工人」两个清单，各自新增、编辑、删除，互不影响
- 删除计件工人会删除其计件记录；删除计时工人会删除其计时记录
- 工资条：单人单月逐行明细，Ctrl+P / 打印按钮自动切白底
- 生产记录页顶部显示本月记录数 / 件数 / 损耗 / 金额四项汇总
- 表格区独立滚动、表头吸顶；等待录入时不用来回滚动页面
- 编辑后右下角出现保存栏并自动保存，状态显示「已保存 时:分」；Ctrl+S 可手动保存
- 删除改为即时删除 + 「撤销」提示，误删可一键恢复
- 页头常驻 CSV 同步状态；导航「数据」可导出 JSON 备份、导出计件/计时 CSV、恢复备份
- 月度汇总页：全部工人的计件金额、记录数、件数、损耗，支持搜索和导出 CSV
- 批量工资条页：一次打印本月所有有记录工人的工资条，一张一页
- 结算状态：未结算 / 已核对 / 已发放；标记已发放后，生产记录页锁定该月，需回汇总页解锁
- 自动备份：每次保存后最多每 5 分钟生成一个浏览器内快照，保留最近 10 个；「数据」弹窗可恢复任意快照
- 每日提醒：首次打开时提示导出 JSON 备份，可一键导出或当天不再提醒；恢复的快照不会被 CSV 自动导入覆盖
